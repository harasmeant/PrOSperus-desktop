# Contribuir a PrOSperus desktop

Puedes crear un fork y modificar el proyecto conforme a [GPLv3](LICENSE). Para proponer una mejora al repositorio oficial, abre una pull request que explique el problema, el cambio y cómo lo has comprobado.

Nicolás (harasmeant) decide qué cambios se incorporan a la rama oficial. Crear o distribuir una variante no exige que su propuesta sea aceptada aquí. Tampoco existe obligación de enviar modificaciones privadas.

Las contribuciones destinadas a incorporarse al proyecto deben poder distribuirse bajo `GPL-3.0-only`. Conserva las atribuciones y declara cualquier código o recurso de terceros y su licencia. No incluyas notas personales, credenciales ni configuraciones privadas.

Antes de enviar cambios de comportamiento, ejecuta las comprobaciones pertinentes de [VALIDATION.md](docs/VALIDATION.md).
