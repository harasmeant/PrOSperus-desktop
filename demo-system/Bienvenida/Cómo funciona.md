# Cada carpeta, un espacio

El mapa muestra archivos y subcarpetas. Cambiar de proyecto recupera sus notas abiertas, mientras la aplicación sigue en marcha.

## Una experiencia familiar

- **Carpetas** muestra tus escritorios en cuadrícula. Moverte con las flechas no cambia el escritorio: pulsa Intro o haz clic en la tarjeta.
- **Fijar** mantiene el tarjetero visible. Si no está fijado, se recoge al salir.
- Las subcarpetas heredan el wallpaper de su proyecto.
- Las ventanas minimizadas aparecen destacadas en la barra inferior.
- **Explorar** permite recorrer carpetas y buscar notas.
