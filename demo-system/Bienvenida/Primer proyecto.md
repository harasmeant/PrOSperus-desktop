# Tu primer proyecto

Un proyecto puede ser un curso, una investigación o una idea.

1. Pulsa **Nuevo proyecto** para crear un espacio en Tus proyectos.
2. Dentro, usa **Nueva nota** para escribir su propósito.
3. Guarda los cambios y vuelve al mapa.

Un archivo llamado `wallpaper.png` en la carpeta personaliza su fondo. Las subcarpetas lo heredan.

Si ya tienes un proyecto, abre **Carpetas → Importar proyecto** para copiarlo.
También puedes seleccionar carpetas y notas, usar **Ctrl+C**, entrar en el
destino y pulsar **Ctrl+V**. **Ctrl+D** duplica la selección. Los originales se
conservan; los nombres repetidos reciben el sufijo « - copia».
