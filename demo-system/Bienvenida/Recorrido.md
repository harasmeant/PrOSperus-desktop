# Un recorrido de cinco minutos

1. Muévete por la cuadrícula de escritorios con las flechas: el proyecto actual se mantiene hasta que pulses Intro.
2. Abre **Laboratorio** y después **Apuntes**: el fondo azul se conserva.
3. Busca `hipotesis`, sin acento.
4. Abre una nota, minimiza y recupera.
5. Crea una nota de prueba, escribe y guarda.
6. Abre **Aplicaciones** para buscar una herramienta instalada en Fedora.

La aplicación elegida se abre con sus permisos habituales dentro de Fedora.
