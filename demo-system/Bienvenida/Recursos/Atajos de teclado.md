# Atajos de teclado

- **Ctrl+B**: abrir o cerrar el tarjetero.
- **Ctrl+1…9**: cambiar de proyecto.
- **Ctrl+L**: buscar notas.
- **Ctrl+O**: abrir la primera nota.
- **Ctrl+N**: crear una nota.
- **Ctrl+S**: guardar en la ventana de nota enfocada.
- **Ctrl+Inicio**: todos los proyectos.
- **Escape**: cerrar el tarjetero o la nota superior.

En el tarjetero: rueda o flechas para recorrer; Intro para abrir.
