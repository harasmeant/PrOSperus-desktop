# Estado de referencia 0.0

Fecha: **27 de octubre de 2026**. La etiqueta `v0.0` identifica el inicio público del proyecto de distro, basado en el prototipo aceptado de Obsidian.

El manifiesto original del complemento conserva su versión `0.1.0`. No es la numeración de la distribución.

## Preparación para publicación

Se copiaron `main.js`, `styles.css`, `manifest.json`, `applications.py` y `test_applications.py` del prototipo. Solo se sustituyeron nombres de proyectos en las paletas y el acceso predeterminado de `main.js` por nombres de demostración. Se mantuvieron los valores de color y la lógica. Los otros cuatro archivos se conservan sin cambios.

Los hashes SHA-256 anteriores a esa adaptación se registran en `evidence/source-sha256.json`. La copia local privada de cierre se conserva fuera de este repositorio.

La documentación pública y las notas de demostración se escribieron para esta publicación. Se excluyeron las notas reales, capturas con texto personal, fondos del entorno local, copias de seguridad, preferencias guardadas, catálogo de aplicaciones instaladas y configuración de otros complementos.

La evidencia de interfaz corresponde al prototipo original anterior a la adaptación de nombres. No se presenta como una nueva ejecución sobre la copia pública.
